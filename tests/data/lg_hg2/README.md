# LG INR18650-HG2 test files

Processed from P. Kollmeyer, M. Naguib and M. Skells, LG 18650HG2 Li-ion Battery Data, Mendeley Data v2 (2020), doi:10.17632/b5mj79w5w9.2, licensed **CC BY 4.0**. The tests were performed at McMaster University by Dr. Phillip Kollmeyer.

Unchanged copies of the pulse (HPPC) test and the C/20 discharge (with its charge) at each of 40, 25, 10, 0, -10 and -20 degC: what `packtherm fit` fits the cell on, with the drive cycles and discharges in `validation/data/lg_hg2/`. Copied by `validation/prepare_mcmaster.py hg2`.
