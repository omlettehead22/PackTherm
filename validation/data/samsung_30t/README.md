# Samsung INR21700-30T test set

Processed from P. Kollmeyer and M. Skells, Samsung INR21700 30T 3Ah Li-ion Battery Data, Mendeley Data v2 (2023), doi:10.17632/9xyvy2njj3.2, licensed **CC BY 4.0**. The tests were performed at McMaster University by Dr. Phillip Kollmeyer.

Changes from the original: tests selected (role `fit`: fitted to; `validation`: never fitted to), non-finite and duplicate-time samples removed, a cooling soak before each test trimmed to 60 s, resampled to exact 1 s bin means (current sign flipped so discharge is positive), battery case temperature interpolated at bin centres, samples of a block logged twice dropped, a lone temperature reading more than 5 K from both neighbours replaced by their mean. The dataset has no chamber channel: the ambient is the cell temperature at the end of the settled rest before each test, and a test whose file starts with the discharge running starts below full by the charge the tester counted before it (see `ambient_from` and `soc0_from` in the manifest); the rest after a test is cut where the chamber's ramp for the next charge begins (`tail_cut_s`). Runs that discharged under a quarter of the capacity (aborted or empty) are left out and listed in `excluded.json`. Generated by `validation/prepare_mcmaster.py 30t`.
